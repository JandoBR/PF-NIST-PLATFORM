# Anexo operativo — proveedor LogiTrack

## 1. Servicio contratado

LogiTrack presta el servicio de seguimiento de envíos para la operación de última milla. El
servicio incluye la integración con la plataforma de recaudo y el soporte de segundo nivel.

## 2. Seguridad

El proveedor notificará cualquier incidente de seguridad al CISO del cliente dentro de las 24 horas
siguientes a su detección y permitirá auditorías anuales con aviso previo de diez días hábiles.
